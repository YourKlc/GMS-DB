# 数据库结构与条目类型

主库 `assets/maplestory_db.json` 为 JSON 格式，顶层为数据库元信息 + 条目数组。

## 顶层结构



```
{

&#x20; "game": "MapleStory GMS",

&#x20; "version": 1,

&#x20; "updated\_at": "2026-09-26",

&#x20; "entries": \[]

}
```



* `entries`：所有条目的数组，是查询与写入的唯一对象。

## 单条目通用字段



| 字段          | 类型     | 必填 | 说明                                   |
| ----------- | ------ | -- | ------------------------------------ |
| `id`        | string | 是  | 唯一 ID，格式 `{类型}_{4位序号}`，如 `item_0001` |
| `type`      | string | 是  | 条目类型（见下表）                            |
| `name_zh`   | string | 是  | 中文名 / 常用称呼（可含别名，用 `；` 分隔）            |
| `name_en`   | string | 否  | 英文官方名                                |
| `content`   | string | 是  | 详细说明：数值、机制、效果、出处等                    |
| `tags`      | array  | 否  | 检索用标签，如 `["消耗品","恢复"]`               |
| `image_url` | string | 否  | 图片链接（仅链接，不存图）                        |
| `source`    | string | 是  | `user`= 用户录入；`wiki`= 收集并经确认          |
| `added_at`  | string | 是  | 录入日期 `YYYY-MM-DD`                    |

## 条目类型（type 取值）



| type     | 含义            | 典型 content 内容         |
| -------- | ------------- | --------------------- |
| `item`   | 道具 / 装备 / 消耗品 | 名称、等级需求、效果 / 属性、获取途径  |
| `job`    | 职业 / 技能       | 职业定位、转职路线、核心技能描述      |
| `quest`  | 任务 / 剧情       | 任务名、前置条件、流程、奖励        |
| `map`    | 地图 / 副本       | 地图名、推荐等级、入口、Boss / 掉落 |
| `boss`   | 首领怪           | 名称、等级、血量、掉落、打法要点      |
| `npc`    | 非玩家角色         | 名称、位置、功能（商店 / 任务等）    |
| `system` | 玩法 / 数值机制     | 系统规则、数值公式、功能说明        |
| `guide`  | 攻略 / 答疑       | 打法、加点、养成、常见问题解答       |
| `event`  | 活动            | 活动名、时间、参与方式、奖励        |

若某资料不属于上述类型，可用最贴近的类型并注明，或新增类型（需同步更新本表与 `id` 前缀）。

## 示例条目



```
{

&#x20; "id": "item\_0001",

&#x20; "type": "item",

&#x20; "name\_zh": "紫苹果",

&#x20; "name\_en": "Purple Apple",

&#x20; "content": "消耗品。使用时恢复 500 点 HP，供日常刷图使用。",

&#x20; "tags": \["消耗品", "恢复", "HP"],

&#x20; "image\_url": "",

&#x20; "source": "user",

&#x20; "added\_at": "2026-09-26"

}
```
